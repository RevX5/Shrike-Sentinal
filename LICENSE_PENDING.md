# Licensing

## Original software

`LICENSE-MIT` is intended to cover original software components of Shrike Sentinel, including the RP2040 firmware, PIO program, and supporting build configuration, provided those files are original work and are not subject to conflicting upstream terms.

## FPGA hardware design

The original FPGA top-level design has not yet been assigned a separate license. Do not assume that `LICENSE-MIT` covers the FPGA design.

The design instantiates Vicharak's `spi_target` module. See `THIRD_PARTY_NOTICES.md` and preserve the applicable upstream license and notices.

## Third-party components

Third-party components remain subject to their respective upstream licenses. Review their original license files before redistributing them.

## Publication status

The license scope for the original FPGA design must be resolved before treating the repository's licensing as complete.
